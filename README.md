# PARCEL OS
## A collaborative WebOS!

This is ParcelOS, a nice little project I've been working on for Crossroads! Just open it in your browser (https://richardkiselev.github.io/PassTheParcel/).

Here are the neat features:
- App icons: click them to open draggable windows
- Random background upon launch, can be changed in an app
- Apps for information
- Cat clicker game!
- Malware! When you click it, it opens 20 windows of a silly pop-up in an attempt to emulate old windowspam malware.
- Time and date!
- Easy modular additions. Anyone can add apps just by sending over an index.html. That's why it's a COLLABORATIVE WebOS. Hopefully, I'll get some peeps sending in apps which I can add.
